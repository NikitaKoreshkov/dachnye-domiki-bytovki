# Изображения для Hero-блока

## house.jpg
- **Размер**: 2700x900px (соотношение 27:9)
- **Формат**: JPG, WebP или PNG
- **Содержание**: Панорамное фото каркасного дома снаружи
- **Качество**: Высокое разрешение для четкости на всех устройствах
- **Стиль**: Современный, премиальный вид

## Рекомендации по изображению:
- Дом должен быть хорошо освещен
- Красивый ландшафт вокруг дома
- Современный дизайн каркасного дома
- Хорошая контрастность для читаемости текста поверх
